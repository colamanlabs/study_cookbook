### 3. 화면 미러링 방법 선택
```aiignore
안드로이드 화면 미러링 방법 이다.
scrcpy 로 선택했다. 

1. DEX
갤럭시 계열에서만 지원하나, ONE UI 7.0 이상에서는 데스크탑 DEX 연결을 미지원 

2. 삼성 플로우  
갤럭시 계열에서만 자원
ONE UI 7.0 이상 지원
WIFI 로 연결한다.

3. 윈도우 11의 핸드폰과 연결
화면 미러링은 단말기에서 지원할 경우만 가능하다.
iplay 70 mini pro 에서는 안된다.
WIFI 로 연결한다.

4. scrcpy
USB 디버깅을 통한 화면연결 
iplay 70 mini pro 에서 가능하다.
WIFI 가 아닌 USB 직연결에라, 반응속도(응답속도)가 빠르다.
```
